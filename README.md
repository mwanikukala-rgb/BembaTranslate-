# BembaTranslate v4

Offline English → Bemba dictionary/translator Android project.

## Included data
- Corrected everyday phrases and greetings
- Family and relationship vocabulary
- Animals, snakes, birds, trees and fruit trees
- Body parts
- Adjectives and colours
- Numbers, days and months
- Pronouns, conjunctions and selected grammar reference entries
- Corrected forms supplied by the project owner are preserved, including Imbwa, Imbushi, Inkumba, Insoka and Umwana.

## Offline
The dictionary data is bundled locally in the Android app. No cloud API is required for dictionary lookup.

## Build
Open the project directory in Android Studio and sync/build with the Android Gradle Plugin version specified by the project.
